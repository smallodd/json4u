# Privacy

This independent deployment processes JSON editor content in your browser. It does not provide an application API that receives, stores, or analyzes the JSON you edit.

## Local storage

The editor stores preferences, such as view settings, in your browser's IndexedDB and cookies. You can clear them through your browser settings.

## User-initiated network requests

Features such as URL parsing and image preview request the URL entered by you from your browser. Use them only with URLs you trust.

## Optional integrations

The operator may configure Google Analytics or Google AdSense. Those scripts are not loaded unless explicitly configured for this deployment. If enabled, their processing is governed by Google's policies.

## Contact

For privacy questions, contact this deployment's operator through the feedback link, if one is provided.
